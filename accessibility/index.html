Accessibility

SHIAGENT aims toward WCAG 2.2 Level AA. This is a direction and ongoing work, not a claim of full conformance.

Last updated: September 29, 2026

Implemented

  • Semantic headings, labels, fieldsets and native controls where practical.
  • Keyboard-visible focus, skip links and keyboard-operable file drop areas.
  • Status messages using live regions on processing tools.
  • Text alternatives for meaningful example images.
  • Reduced-motion support through the user's operating-system preference.
  • Responsive layouts and browser zoom support.

Known limitations

  • Complex canvas editors may require pointer input for precise drawing.
  • Drag-based PDF and file ordering is not yet equally efficient with a keyboard on every page.
  • Automatic color contrast and screen-reader testing is not yet continuous across every release.
  • Generated previews can contain visual information not fully described in surrounding text.

Standard and testing

The target reference is WCAG 2.2, with Level AA as the working goal. Automated tests catch structural regressions, but manual keyboard, screen-reader, zoom and high-contrast review remains necessary.

Report a barrier

Use the Feedback page, select Accessibility, and include the tool, browser, assistive technology and exact step where access became difficult.
