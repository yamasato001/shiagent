USE CASES

Start from what you need to do.

Every tool does one job well. Pick the step you need, check the result and save it. No installation and no account required.

  1. 01

    Make images smaller

    Choose PNG, JPEG or WebP → pick a mode → compare → save

    Open Image Compressor →
  2. 02

    Turn line art into vectors

    Choose PNG, JPEG or WebP → set quality and size → save as SVG

    Open Image to SVG →
  3. 03

    Split a sprite or sticker sheet

    Choose an image → detect white space → save PNGs or a ZIP

    Open Image Splitter →
  4. 04

    Remove or replace a background

    Choose images → detect the background → save transparent or on a solid color

    Open Background Remover →
  5. 05

    Tidy up file names

    Add any files → set a naming rule → save as a ZIP

    Open Batch Rename →
  6. 06

    Fill closed SVG areas with white

    Choose SVGs → detect closed areas → add white fill paths

    Open Automatic SVG White Fill →
  7. 07

    Clean up SVG code

    Choose SVGs → remove unneeded data → compare → save

    Open SVG Cleaner →
  8. 08

    Adjust SVG white fills by hand

    Choose SVGs → add guide lines or exclusions → preview → save

    Open Manual SVG White Fill →
  9. 09

    Resize a batch of images

    Add images → set pixels or percentage → download separately or as a ZIP

    Open Image Resizer →
  10. 10

    Normalize image margins and canvases

    Add images → Auto Trim or Normalize → download as a ZIP

    Open Image Cropper →
  11. 11

    Remove private image metadata

    Add PNG, JPEG or WebP → remove EXIF, GPS and more → download as a ZIP

    Open EXIF Cleaner →
  12. 12

    Combine multiple images into one

    Add images → choose horizontal, vertical or grid → save one image

    Open Image Joiner →
  13. 13

    Turn SVGs into images

    Add SVGs → set size and background → download images or a ZIP

    Open SVG to Image →
  14. 14

    Add space around images

    Add images → choose percentage, pixels or a fixed canvas → download a ZIP

    Open Canvas Padding →
  15. 15

    Change asset colors in a batch

    Add images or SVGs → choose a color and tolerance → replace or make transparent

    Open Replace Color →
  16. 16

    Create favicons and PWA icons

    Add one image → set fit and background → download ICO, PNGs and manifest in a ZIP

    Open Favicon Generator →
