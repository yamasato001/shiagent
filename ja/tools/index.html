画像トリミング

IMAGE

余白追加

画像の周囲に％・px余白を足すか、指定Canvasの中央へまとめて配置します。

IMAGE

背景削除・背景色

単色の背景を透明にし、白・黒・任意の色の背景へまとめて差し替えます。

一括リネーム

VECTOR

SVG手動白塗り

補助線と除外指定をキャンバス上で追加し、SVGの白塗り結果を手動で調整します。
ON DEVICE

PDF

PDFツール

専用ワークスペースで結合・分割・並べ替え・交互結合・回転・ページ削除を行います。
WORKFLOW

IMAGE

Web画像最適化

ブログ・サムネイル・元サイズから選び、変換・圧縮・メタデータ削除・任意のリネームまで一括処理します。

Crop → Resize → Convert → Compress → Metadata → Rename
WORKFLOW

VECTOR

線画をSVG素材にする

トリミング・背景処理・SVG化・白フィル（塗りつぶし）・クリーナーをひとつの流れで実行します。

Trim → SVG → White Fill → Clean
WORKFLOW

IMAGE ASSETS

AI画像素材一括仕上げ

AI生成画像をまとめて、余白・サイズ・連番名・形式・容量を使える素材へ整えます。

Auto Trim → Normalize → Resize → Rename → Compress
WORKFLOW

IMAGE ASSETS

画像素材の規格統一

バラバラな画像を、同じCanvas・対象物・余白・背景・形式・連番名へまとめて統一します。

Detect → Normalize → Background → Convert → Rename
WORKFLOW

PDF

PDFのページ順を復元

向きを補正し、四隅と端のページ番号を読み取り、複数PDFを正しい順番へ整理します。

向き判定 → 外周OCR → 並べ替え
BETA

ORIGINAL

オリジナル

画像・SVG・PDF・ファイルの対応ツールを自由につなぎ、自分用のWorkflowをローカル保存できます。

選択 → 並べ替え → ローカル保存
