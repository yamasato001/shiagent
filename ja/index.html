LOCAL-FIRST CREATIVE TOOLKIT

つくる。整える。仕上げる。

画像・SVGを、ブラウザだけで。素材を「実際に使える状態」まで仕上げるための、シンプルな道具箱です。

Runs on your device — ファイルはブラウザの外に出ません。

USE CASES

目的から、道具を選ぶ。

入口は単機能。必要な処理だけを選び、結果を確認して保存できます。インストールやアカウント登録は必要ありません。

  1. 01

    画像を軽くする

    PNG・JPEG・WebPを選択 → 圧縮方式を選択 → 比較 → 保存

    画像圧縮を開く →
  2. 02

    線画をベクターにする

    PNG・JPEG・WebPを選択 → 品質とサイズを指定 → SVGで保存

    画像 → SVG変換を開く →
  3. 03

    素材シートを分割する

    画像を選択 → 余白を検出 → 個別PNGまたはZIPで保存

    画像分割を開く →
  4. 04

    背景を透明にする・差し替える

    画像を選択 → 背景色を自動検出 → 透明または単色で保存

    背景削除を開く →
  5. 05

    ファイル名をまとめて整える

    あらゆるファイルを追加 → 命名ルールを指定 → ZIPで保存

    一括リネームを開く →
  6. 06

    SVGの閉領域を白くする

    SVGを選択 → 閉領域を検出 → 白塗りパスを追加

    SVG自動白塗りを開く →
  7. 07

    SVG内部を整理する

    SVGを選択 → 不要情報を除去 → 前後比較 → 保存

    SVGクリーナーを開く →
  8. 08

    SVG白塗りを手動で調整する

    SVGを選択 → 補助線・除外を指定 → プレビュー → 保存

    SVG手動白塗りを開く →
  9. 09

    画像サイズをまとめて変更する

    画像を追加 → pxまたは％を指定 → 個別またはZIPで保存

    画像リサイズを開く →
  10. 10

    画像の余白とCanvasを揃える

    画像を追加 → Auto TrimまたはNormalize → ZIPで保存

    画像トリミングを開く →
  11. 11

    画像の位置情報を消す

    PNG・JPEG・WebPを追加 → EXIF・GPS等を削除 → ZIPで保存

    メタデータ削除を開く →
  12. 12

    複数画像を1枚にまとめる

    画像を追加 → 横・縦・Gridを選択 → 1枚で保存

    画像結合を開く →
  13. 13

    SVGを画像にする

    SVGを追加 → サイズ・背景を指定 → 画像またはZIPで保存

    SVG → 画像を開く →
  14. 14

    画像の周囲に余白を追加する

    画像を追加 → ％・px余白またはCanvasを指定 → ZIPで保存

    余白追加を開く →
  15. 15

    素材の色をまとめて変える

    画像・SVGを追加 → 色とToleranceを指定 → 置換または透明化

    色置換ツールを開く →
  16. 16

    FaviconとPWAアイコンを作る

    画像を1枚追加 → 配置と背景を指定 → ICO・PNG・manifestをZIP保存

    Favicon生成を開く →

LOCAL-FIRST

Runs on your device.

処理は可能な限りブラウザ内で完結します。画像を外部サーバーへアップロードせず、その場で変換して保存できます。

01インストール不要
ページを開けば、そのまま使えます。
02アップロード不要
ファイルの読み書きは端末内で完結します。
03結果を見て判断
変換前後とサイズを確認してから保存できます。
