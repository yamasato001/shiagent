FAQ

Common questions

Are my files uploaded?＋

No. SVG loading, selection, style changes and saving all happen inside your browser.

What can I change?＋

You can change each part's fill, stroke color, stroke width and opacity, including no fill or no stroke.

Can I change every visible area of the same color?＋

Yes. Choose Select same color and click the color to change. Matching fills and strokes are selected as one visible color. Black parts and White parts provide direct shortcuts.

Can I select several objects?＋

Yes. In Select objects mode, drag the background for box selection. Ctrl+A and the Select all button select every part.

Can I undo changes?＋

Undo and redo are supported. You can also restore only the current SVG to its loaded state.

Is it safe to open SVG files?＋

Scripts, event attributes and external references are removed before preview. Complex external CSS or embedded content may not be preserved.
