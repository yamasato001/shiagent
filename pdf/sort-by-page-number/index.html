HOW IT WORKS

Orient, read, and reorder.

01

Text coordinates and page pixels identify the top of each page before number detection begins.

02

Analyze the perimeter

The workflow checks all four edges and corners. It uses embedded text first and numeric OCR for scanned pages.

03

Review and save

Check detected numbers, unresolved pages, duplicates and gaps. Manual edits immediately update the proposed order.

FAQ

Frequently asked questions

Does it work with scanned PDFs?＋

Yes. Pages without embedded text are rendered locally and their edge regions are analyzed with numeric OCR.

What happens to covers without page numbers?＋

Unnumbered pages before the first numbered page stay at the beginning. Other unnumbered pages remain attached to the preceding numbered page.

Can dates or document IDs be mistaken for page numbers?＋

The workflow scores position, formatting and consistency across pages. Low-confidence candidates, duplicates and gaps are flagged for review.

Will image quality change?＋

No. The workflow updates page order and rotation metadata without recompressing page content.

Are PDFs uploaded?＋

No. Orientation detection, OCR, sorting and PDF generation all run in your browser.
