About this technical preview

Can this model ship in the commercial product?＋

The current SD-Turbo ONNX model is a non-commercial technical proof of concept. It will be replaced by a commercially usable line-art model before release.

Which browsers are supported?＋

Current Chrome or Edge with WebGPU and shader-f16. The large model also needs sufficient GPU memory and local storage.

Does generation use the network?＋

Inference is local after installation. Network access is used for the initial model and tokenizer downloads.
