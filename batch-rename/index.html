FAQ

Common questions

Which file types are supported?＋

Any file selectable by your browser is supported, including images, PDFs, Office documents, text, audio, video, archives and files without extensions.

Are my files uploaded?＋

No. Renaming, ZIP creation and handing compatible files to the next tool all happen inside your browser.

In what order are numbers assigned?＋

In the order shown in the list of changes, which is the order you added the files.

Does the file extension change?＋

No. The original extension, including its letter case, is kept. The file contents are not changed.

What happens to characters that are not allowed?＋

Characters that cannot be used in file names, such as \ / : * ? " < > |, are removed automatically.

What if two files end up with the same name?＋

An error is shown and the names are not applied. Change the base name or the start number.
