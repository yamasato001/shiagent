FAQ

Frequently Asked Questions

Common questions about files, privacy, compatibility and results.

Last updated: September 29, 2026

Files and privacy

Are my files uploaded?

No, unless a tool page explicitly says otherwise. Current production tools process files in the browser.

Why do files remain in the Work Tray?

The tray uses browser IndexedDB so you can continue in another SHIAGENT tool. Clear the tray or site data to remove them.

Can the site read other files?

No. A page can read only files you explicitly select, drop or grant through a browser picker.

Limits and results

Is there a file-size or batch limit?

SHIAGENT adds no general hard limit. Available memory, browser canvas limits and file complexity determine the practical limit.

Why does the output differ from the preview?

Browser color management, SVG fonts, image codecs and export settings can differ. Always inspect the downloaded file.

Why did a large job fail?

Try fewer files, smaller dimensions, closing other tabs, or a current desktop Chrome/Edge browser.

Use and support

Can I use outputs commercially?

The tool does not take ownership, but you must have the rights to the source files and comply with any underlying licenses.

Does it work offline?

After required scripts and Wasm are loaded, many operations can continue in the open tab, but offline availability is not guaranteed because no offline cache is currently installed.

Where can I report a problem?

Use the Feedback page to create a structured report. An external submission destination is still being prepared.
