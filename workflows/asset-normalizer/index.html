ASSET NORMALIZER

Make inconsistent images behave like one asset set.

Asset Normalizer is designed for batches, not one-off edits. It converts varied source images into predictable files with an exact canvas, consistent visual scale, controlled empty space, one background, one format and sequential names.

Object occupancy is a maximum. If the requested padding needs more room, the object is reduced so neither setting is violated.

FAQ

Common questions

Are my images uploaded?＋

No. Detection, resizing, conversion, naming and ZIP creation all run inside your browser.

What does Object 80% mean?＋

The detected object can occupy up to 80% of the canvas width or height while preserving its aspect ratio.

How does padding interact with object size?＋

Both are enforced. The smaller valid scale is used, so the object never exceeds its occupancy and the minimum padding remains available.

Can I mix HEIC, JPEG and PNG files?＋

Yes. Supported source formats can be mixed and are exported together as PNG, JPEG or WebP.

What happens to transparency in JPEG?＋

JPEG cannot store transparency, so a transparent background selection is exported as white.
