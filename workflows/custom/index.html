FAQ

Frequently asked questions

What is stored locally?＋

Only the workflow name, starting file type and tool order. Image and PDF files are not stored as part of the workflow.

Why are some tools unavailable?＋

A tool is disabled when it cannot read the previous step's output. The full chain is checked again whenever you reorder it.

Can I use a saved workflow in another browser?＋

The beta saves to this browser's local storage. Cross-device sync is a possible future extension.
