COMPATIBILITY

Formats, Limits & Browsers

There is no artificial upload quota. Real capacity depends on browser memory, file complexity and your device.

Last updated: September 29, 2026

Recommended browsers

Chrome / EdgeRecommended. Use the current stable version. Direct folder saving is available where the File System Access API is supported.
SafariUse the current version. Core processing works, but direct folder saving may be unavailable.
FirefoxCore tools generally work. Some file-system and image-codec features may differ.
Mobile browsersSuitable for small jobs. Desktop browsers are recommended for batches, large images and PDFs.

Supported formats

Raster inputPNG, JPEG/JPG, WebP; selected tools also accept HEIC/HEIF, AVIF, GIF, BMP and TIFF.
Raster outputPNG, JPEG/JPG and WebP, depending on the tool.
VectorSVG input/output. Image-to-SVG accepts PNG, JPEG and WebP.
DocumentsPDF for merge, split, reorder, interleave, rotate and page deletion; PNG/JPEG/WebP for Images to PDF.
PackagesMulti-file results can be downloaded as ZIP or saved directly to a selected folder in supported browsers. The favicon generator also outputs ICO and a Web App Manifest.

Capacity

  • Site-enforced file-size limit: none.
  • Site-enforced batch-count limit: none unless stated on a tool page.
  • Actual limit: available RAM, graphics memory, browser canvas limits and PDF complexity.
  • Large jobs are processed sequentially where supported to reduce peak memory.

If a tab becomes slow, process fewer files at once, reduce image dimensions, or use a desktop browser.

Feature differences

Direct folder saving uses showDirectoryPicker(), which is not available in every browser. When unavailable, ZIP or individual downloads remain available. HEIC/TIFF decoding and very large canvases can vary by source file and browser.
